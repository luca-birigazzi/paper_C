# Interactive figures: bounds on a weighted sum from the mean and variance

- `index.html`: three units (N = 3). The plane H, the sphere and the circle of populations with a given mean and variance; any weight vector can be typed in.
- `n4.html`: four units (N = 4), drawn inside the hyperplane H, where those populations form a sphere.

Non-negativity is optional in both: tick "Require non-negative values".

Each page is a single file. It loads Plotly 2.35.2 from cdn.plot.ly and fonts from Google Fonts, so it needs an internet connection but no build step.
